# PyTorch End-to-End

This repository documents my end-to-end learning journey of PyTorch, starting from fundamentals and progressing to advanced deep learning concepts with clear explanations and runnable examples.

## Why this repository?
- Learn PyTorch by **building and explaining**
- Act as a **reference** for future projects
- Serve as a **portfolio-quality** learning resource

## Topics Covered
- PyTorch tensors and operations
- Autograd and backpropagation
- Neural networks with `nn.Module`
- Training loops and optimization
- CNNs, RNNs, and Transformers
- Model saving, loading, and inference
